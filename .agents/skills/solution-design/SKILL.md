# Solution Design Skill

## Purpose
This skill guides the divergent generation and rigorous evaluation of 3–5 competitive solution concepts, preventing the common hackathon mistake of fixating on the first shallow idea.

## Evaluation Framework

For every generated concept, evaluate across 6 core criteria (scored 1–5):
1. **User Impact**: Degree of pain reduction and workflow transformation.
2. **Innovation & Novelty**: Freshness of approach vs. generic clones.
3. **Technical Feasibility & Speed**: Can an impressive MVP be built reliably within the hackathon time?
4. **Demo Potential**: High visual/interactive appeal within a 3-minute live presentation.
5. **Technical Differentiation**: Real engineering substance (algorithms, schemas, architectures).
6. **Risk Profile**: API dependencies, rate limits, latency bottlenecks.

## Concept Structuring Format

```markdown
### Concept [Name]
- **Core Mechanism**: [How it works]
- **User Experience**: [Key user interaction flow]
- **Technical Differentiation**: [Why it is technically impressive]
- **Estimated Build Complexity**: [Low / Med / High]
- **Key Risks**: [Primary failure modes]
```

## Decision & Selection
- Compare all concepts in a structured trade-off table.
- Formally recommend the highest-ROI solution that balances **Innovation + Demo Reliability + Speed**.
