# Documentation Skill

## Purpose
This skill ensures that all project documentation, architecture logs, API references, and submission summaries remain 100% accurate, up to date, and compelling for review.

## Documentation Principles
1. **Synchronous Updates**:
   - Update [`docs/current-state.md`](file:///c:/Users/Pratam%20Jain/Desktop/Runtime%20Terrorists/docs/current-state.md) immediately whenever major components or features are merged.
   - Record significant technical trade-offs in [`docs/decisions.md`](file:///c:/Users/Pratam%20Jain/Desktop/Runtime%20Terrorists/docs/decisions.md).
2. **Clarity & Brevity**:
   - Write clear, active prose. Avoid marketing fluff or unsupported technical claims.
3. **Diagrammatic Accuracy**:
   - Ensure ASCII/Mermaid architecture diagrams reflect the actual codebase structure and data flow.
4. **Devpost & Submission Ready**:
   - Format project narratives with crisp headings: Inspiration, What it does, How we built it, Challenges we ran into, Accomplishments, What's next.
