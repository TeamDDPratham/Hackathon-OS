# 3-Minute Live Demo Script & Runbook

> **Target Duration**: Exactly 3 Minutes (180 Seconds)  
> **Golden Rule**: Show, don't tell. User value first, technical depth second.

---

## Timing Breakdown

```text
00:00 - 00:30 (30s) │ Hook & The Pain Point
00:30 - 01:15 (45s) │ Core User Workflow in Action
01:15 - 02:00 (45s) │ The Killer Feature ("Wow" Moment)
02:00 - 02:40 (40s) │ Technical Architecture & Differentiation
02:40 - 03:00 (20s) │ Impact, Vision & Closing
```

---

## 1. Opening & Hook (00:00 – 00:30)
- **Visual**: Problem slide / Live blank state showing real-world friction.
- **Spoken**: *"Every day, [Target Persona] loses [X hours / \$Y] trying to [Action]. Current tools fail because [Fatal Flaw]. Today, we built [Product Name]."*

---

## 2. The Core Solution (00:30 – 01:15)
- **Visual**: Live interactive application in browser.
- **Action**: Perform Step 1 $\to$ Step 2 of the primary user flow.
- **Spoken**: *"Watch how seamlessly [Persona] can now [Action]. In just two clicks, our system parses [Input] and resolves [Problem]."*

---

## 3. The Killer Feature / "Wow" Moment (01:15 – 02:00)
- **Visual**: Trigger the technical differentiator (e.g., real-time synthesis, multimodal analysis, instant graph generation).
- **Action**: Execute the high-impact feature with live response.
- **Spoken**: *"Here is where it gets powerful. When we trigger [Killer Feature], our engine [Explain AI/Algorithmic magic] in under a second."*

---

## 4. Technical Explanation & Differentiation (02:00 – 02:40)
- **Visual**: Architecture slide / Clean system diagram or developer inspection.
- **Spoken**: *"Under the hood, we designed a [Modular Architecture]. Rather than relying on simple wrappers, we built [Custom AI Pipeline / Schema Validation / Real-time Engine] ensuring sub-second response times and zero hallucination risk."*

---

## 5. Impact, Future Potential & Closing (02:40 – 03:00)
- **Visual**: Summary slide / Clean product dashboard view.
- **Spoken**: *"[Product Name] turns hours of painful work into seconds of effortless clarity. Thank you, and we're ready for your questions."*

---

## Emergency Fallback Protocols
- **If Live API Fails**: Switch immediately to Tab 2 containing pre-cached response / recorded live video backup without breaking narrative flow.
- **If Internet Disconnects**: Run against local Docker / mock seed data pre-configured on localhost.
